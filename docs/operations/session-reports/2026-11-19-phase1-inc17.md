## Issues found and fixed
- Jackson 3 rejects a missing JSON field bound to a primitive `boolean` (requests without
  `requestApproval` failed with "Failed to read request"); optional flags are now `Boolean`, and an
  omitted consent gets a clear "consent" message.
- The browser journey caught a real UI bug: refreshing balances after posting replaced the page
  with a loading indicator and lost the teller's confirmation (including the "do not pay out"
  warning). Pages now keep their content while refreshing; a UI test with realistic latency fails
  on the old code and passes on the fix.
- Check labels and test entry ids clashed with earlier database tests -> D-series, new ids.

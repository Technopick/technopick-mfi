## Issues found and fixed
- **Two runs at once were possible:** a run older than 10 minutes was treated as interrupted, but
  month end on the load-test book takes several minutes, so a long live run could have been
  resumed beside itself. Now the run lock decides. The test holds the lock from another connection
  and shows the run is refused (and the scheduler leaves it alone), then resumes once that
  connection closes.
- A cut-off time after midnight would have closed a business date at the start of that day; times
  before noon now mean the early hours after it.
- First CI run: the new API test had no `integration` tag (no Docker on Windows), and its injected
  failure never fired on an empty book. Both fixed before the docs.

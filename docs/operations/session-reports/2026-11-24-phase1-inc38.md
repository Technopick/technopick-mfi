## Issues found and fixed
- The browser journey showed the account picker defaulting to the first account (B2C), so a
  paybill statement went to the B2C account. The account is now an explicit choice, and a file
  whose header names another short code is refused.
- The load test showed the upload taking 14.6 s for 2,401 lines: new lines have no planner
  statistics, so matching ran in a nested loop (5.8 million row checks). Candidates are now
  materialised and hash-joined: 7.5 s to 0.12 s locally, 0.86 s for the whole upload in CI.
- A file input marked required blocked form submission in the unit test environment; the button
  is disabled until a file is chosen instead. A test map needed explicit generic types.

## Issues found and fixed
- Database tests expected trigger errors where the application role has no DELETE or UPDATE grant
  at all; both refusals are now accepted.
- The first browser run failed because the test handset let the next key be sent before the
  previous answer arrived. The handset now disables its buttons while waiting, and the journey
  reports the screen if a session ends early. Browser results are now kept when the job fails.
- The shared test helper gave every test member the same phone, which USSD rightly refuses; the
  helper now takes a phone number.

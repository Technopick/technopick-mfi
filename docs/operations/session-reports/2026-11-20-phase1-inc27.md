## Issues found and fixed
- Chaining by the identity column would break under concurrent requests (identity values can be
  handed out in a different order from commits); the chain number is assigned under the
  per-tenant lock instead.
- As a plain servlet filter the audit ran outside the security chain in tests (and depended on
  container filter ordering); it now runs inside the chain after authorization.
